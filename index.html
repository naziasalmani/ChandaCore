How It Works

Discover how an ancient system of poetic patterns can be represented, generated, analyzed, and explored through computational thinking.

01 — Ancient Knowledge

Pingala's Chandaśāstra

ChandaCore is inspired by Pingala's Chandaśāstra, an ancient Indian work concerned with poetic meter and patterns of Laghu (short) and Guru (long) syllables.

L
Laghu Short Syllable (1 Matra)
G
Guru Long Syllable (2 Matras)
02 — Binary Encoding

Laghu & Guru → 0 & 1

By representing Laghu as 0 and Guru as 1, each syllable pattern can be represented as a binary sequence.

L ↓ 0
G ↓ 1
G ↓ 1
L ↓ 0
LGGL  →  0110
03 — Pattern Generation

Every Pattern Has a Possibility

For a pattern of length n, there are 2n possible Laghu–Guru combinations.

2n

Example for n = 3 (23 = 8 patterns):

LLL
LLG
LGL
LGG
GLL
GLG
GGL
GGG
Total: 23 = 8
04 — Combinatorics

Patterns Follow Structure

If exactly k positions contain Guru syllables, the number of possible patterns is given by C(n, k) = n! / (k!(n - k)!).

C(n,k) = n! / (k!(n - k)!)
